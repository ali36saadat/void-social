## Installation
**Requirements:** `nvm`, `node`

1: nvm
```node js
nvm use
```
1: Install Dependencies
```node js
npm install
```
2: Compile and Run the project
```node js
ng serve
```

> [!NOTE]
> Package updates and dependency changes may cause some issues when getting the project up and running
